## Affected Pages/Routes
- CLI: `tpo skills install`, `tpo skills uninstall`, `tpo recover-counter`, and todos-manager runtime docs.

## Key Interactions to Verify
- Reinstall refuses by default, replaces only with `--reinstall`, and rolls back failed replacements.
- Uninstall requires `--yes`, preflights all targets, removes existing installs, and preserves backups when cleanup fails.
- todos-manager `--add` and `--audit` reconcile `NEXT_TODO_ID` across active and archived TODO IDs.

## Edge Cases
- Dangling or ordinary symlink destinations.
- Missing later install parent during `--target all` preflight.
- Malformed, duplicated, stale-low, stale-high, and CRLF `NEXT_TODO_ID` metadata.
