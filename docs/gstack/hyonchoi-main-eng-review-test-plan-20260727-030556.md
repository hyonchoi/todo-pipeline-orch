## Affected Pages/Routes
- CLI: `tpo skills install` — verify absent-destination install, fail-on-exists, explicit `--reinstall`, project/user scope, and `--target all` behavior.
- CLI: `tpo skills uninstall` — verify confirmation, `--yes`, user/project scope, and multi-target preflight before deletion.
- Bundled skill: `todos-manager --init` — verify new projects get a preamble containing the exact blockquote line `> - NEXT_TODO_ID: 1`.
- Bundled skill: `todos-manager --convert` — verify legacy TODO files get `> - NEXT_TODO_ID: <max + 1>` without renumbering existing entries.
- Bundled skill: `todos-manager --add` — verify common-path ID assignment reads and increments tracked `NEXT_TODO_ID`.
- Bundled skill: `todos-manager --audit` — verify stale or missing `NEXT_TODO_ID` is repaired from active plus archived IDs.
- CLI: `tpo recover-counter` — verify compatibility cache recovery uses `NEXT_TODO_ID - 1` when tracked state exists.

## Key Interactions to Verify
- Re-run `tpo skills install` on an existing destination and confirm it fails with Problem/Cause/Fix output unless `--reinstall` is passed.
- Run `tpo skills install --target all --reinstall` where the second target cannot be written and confirm the first target remains untouched.
- Run `tpo skills uninstall --target all --yes` where the second target cannot be removed and confirm the first target remains untouched.
- Add a TODO when `NEXT_TODO_ID` is valid and confirm the new entry uses that ID and the preamble increments only after a successful write.
- Add or audit when `NEXT_TODO_ID` points at an existing active TODO and confirm reconciliation corrects the value before assignment.
- Run audit on `NEXT_TODO_ID: next`, `NEXT_TODO_ID: 0`, duplicate `NEXT_TODO_ID` lines, and a value outside the preamble; confirm each is reported and repaired.
- Run `recover-counter` with tracked state present and confirm `.hermes/todo_id_counter` becomes `NEXT_TODO_ID - 1`.

## Edge Cases
- Dangling symlink at an install destination.
- Existing destination as a regular file rather than a directory.
- Missing `TODOS-archive.md`.
- Archive-only max ID greater than active max ID.
- Legacy `TODOS.md` with no `NEXT_TODO_ID`.
- Malformed `NEXT_TODO_ID`: missing, non-integer, zero, negative, duplicate, or outside the preamble blockquote.
- Failed or interrupted `TODOS.md` write.
- Concurrent or stale writer attempting to use the same `NEXT_TODO_ID`.
- `.hermes/todo_id_counter` present, absent, malformed, stale, and newer than tracked state.
- Runtime-doc/oracle drift: `SKILL.md`, `sections/id-assignment.md`, `sections/schema.md`, demo fixtures, and golden YAML must all agree on the exact line and repair behavior.

## Critical Paths
- Installer safety: absent install succeeds, existing install fails, explicit reinstall succeeds, uninstall confirms before delete.
- Tracked ID safety: `--init`, `--convert`, `--add`, and `--audit` preserve the same `NEXT_TODO_ID` contract.
- Write safety: tracked `TODOS.md` updates hold an exclusive lock across read/reconcile/write, and failed writes leave the original file plus counter cache unchanged.
- Legacy compatibility: `recover-counter` follows tracked state when present and scans only for legacy files without a valid tracked field.
- Verification gate: `uv run pytest tests/test_skills_install.py tests/skill-test-environment` followed by full `uv run pytest`.
